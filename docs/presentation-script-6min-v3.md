## 読み上げ原稿

### ① フック

気持ちを相談したくなったとき、「対話型AI（チャットボットAI）」「大規模言語モデル（LLM）」とは別の場所を作りました。

### ② 結論

Reflective AIです。返事として答えを出さないAIです。何に対するもやもやかなのかを、自分で決める場所です。誰にも届かず、保存されない場を、動くものとして作りました。

### ③ なぜ（山場）

仕事の現場で、辞めたい、雰囲気が悪い、言えない、家庭のことで辞めていく、離職を食い止めたい、外のカウンセラーに入ってほしい、という声を聞いてきました。人の代わりや、離職対策のシステムを作りたかったのではありません。社内、現場で伝えるのを躊躇してしまうが、そこに向き合わないと前に進めないような時に使ってもらいたいと思って作りました。

ChatGPTでいいのではないか、と思いますよね。もちろん役に立ちます。気持ちの相談を、解決すべき課題として受け取ってくれます。

しかし、相談するときには、何に対するもやもやかが、本人にもまだ決まっていないことも多いのです。ですが、ChatGPTなどは、答えを出すために誰が、いつ、何を、どう、誰に、という場の設定を、先に決めてしまいます。

同じ文を、ChatGPTにも投げてみました。同僚の言葉遣いが気になる。私にだけ命令口調になる。言い方を変えてほしい、と。共感のあと、すぐ、こう伝えてください、と台詞が出ます。落ち着いたときに言う長い台詞。その場で返す短い台詞。境界の引き方。最後は、実際のフレーズを出してください、一緒に考えましょう、と、次の作業まで渡してきました。提案がどんどん来ます。私は、考えが追い付きませんでした。速さの話ではありません。自分の考え、気持ちの動きよりも早く結論を出してきた、そんな感覚に陥りました。ChatGPTの答えはもちろん役に立ちます。それでも、まだ自分でも決めていないところまで先に言われると、こんなことまで言われたくない、と感じることもありました。

Reflective AIでは、直接的な解決策を提示しません。普段言えないことが言えるので、自分が抑圧されていた、と気づいたり、こんなこと本当に言ったら、傷つけちゃうな、とも思いました。こう伝えてください、を先に渡していたら、その考えは、私の口から出てこなかったと思います。

返す文を書くこと自体は、汎用AIにもできます。できないのは、返しては止まり、自ら次を提案しないことです。ChatGPTとの差は、解決の方法です。能力ではありません。

### ④ なぜ、残らない場なのか

では、なぜ、誰にも届かない、保存されない場なのか。

企業支援を10年、グループでの相談活動を28年してきました。その現場で、経営者からこう聞きました。社内の人には伝えにくいこともあるだろう。会社の外から聞いてくれる人が必要だ、と。相談の現場では、「話すことで放す」ということも学びました。人の代わりを作ったのではありません。離職を食い止める装置でも、カウンセラーの代替でもありません。

書いたことはここには保存されません。終了したら消えます。通知も、リマインドも、入れていません。残らないこと自体が、本音を書ける条件になるのです。この講座では、画面に記憶を持たせることも学びましたが、あえて記憶させないことで、ここが安心安全の場所だ、と伝えたかったのです。技術を使わないというより、何を残し、何を残さないかを、決めてアプリを作りました。

入口では、「ここは、答えを出さない場所です」と、あえて先に伝えます。効能の約束ではありません。場の約束です。筋書きは出しません。これを言わないと、ChatGPTと同じ棚に置かれます。答えを出していないことを隠すと、途中で「まだ結論は？」と待たれてしまうかもしれません。先に、この場の使い方を説明しています。

### ⑤ なぜ使うのか、使い続けるとどうなるのか

では、なぜ使うのか。カウンセリングの前段階、ではありません。歯のメンテナンスと、歯科治療のように、目的も頻度も違うものです。専門家に頼むほどではないけれど、放置すると蓄積する。日々、言葉にできる場、それを今回制作しました。

ほかの相談アプリは、書いて、分析して、記録が残ります。機能が少ないのではなく、思想が逆なのです。上司と部下の相互理解を深め、信頼関係を築くための組織開発の手法であるアシミレーション、「話し合う」ではなく「聴き合う」ことに重きを置いた、共感を軸にする新しい対話の技術であるレゾナント・コミュニケーションとも違います。こちらは誰にも届けず、記録に積まず、手放します。

使い続けるとどうなるか。私の経験ですが、嫌な声かけを受けたとき、以前なら、嫌だな、悲しいな、で反発して終わっていました。そのときは、なぜ強い言葉が嫌なのか、強いとは何か、など少し違った立場でこのことに向き合うことができたように感じました。強い言葉に焦って慌ててしまう自分に気づいて、「強く言われると焦って答えが見つからない」と伝えてみよう、という次の一手まで、自分で組み立てられました。使うほど、AIなしでも自分で気づける方向に育つ。それが、この Reflective AI を使い続ける意味にならないかなと思っています。

いまは個人が、一人で開く場ですが、将来は、場を用意する側、企業やセミナー、人の集まる場にも届け、使ってもらいたいと思っています。判断しないという約束は、言葉が変わっても同じです。

### ⑥ どう作ったか

もともとオープンダイアローグを学んでいて、アプリにできないかなと思っていました。また、相談の現場で聞いた声が後押しとなっています。

実際に使うことを想定して、知り合いに使ってもらい、感想を聞いて、アプリに反映しました。

たとえば、話す相手についても意見をもらい検証して、聞こえてきた人を並べたあとに、本人が選ぶ形に直しました。

AIの返事は Claude です。技術の検証には Cursor を使い、ChatGPT や Claude にも見てもらいました。学術の裏付けは Claude にしてもらいました。実装は Cursor と Next.js です。動くデモは Vercel に、説明用の図解は Surge に公開しています。

### ⑦ 最後に

ChatGPTとは別の場所として、答えを出さないを、動くものに作り上げました。6か月前には、こんなの作れたらいいなくらいでイメージもできなかったものが、こうして形になったことに感動しています。ドリルを続け、わからない中でも課題に取り組み、疑問に思ったらAIに尋ねる、その尋ね方も考えてからにする、途中ではリポジトリに保存する…などなど、初めはマコさんが何を言っているのかまったくわかっていなくて、グループ討議でもついて行けてない感が満載でしたが、ここまで来て、やっとワードにも慣れてきました。特に falcon のみなさんとご一緒できたことは、何よりの財産となりました。ありがとうございました。
