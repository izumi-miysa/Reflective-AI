# 6分 卒業制作発表原稿（AI Driven School）

## 前提

- 尺: 6分（読み上げ約1700字。間を入れて6分）
- 聞き手: グループ。評価はある。審査はない。運営に提出する
- 言い切ること: 答えを出さないAIを、動くものとして作った
- 山場: 同じ文を ChatGPT に投げたとき、出口が先に来たか来ないか
- いちばん長く: 作り。娘さんが出てきた。「違う、夫の話なのに」。本人が選ぶ形に直した
- 画面: この原稿が先。スライドはあとから、この区切りに合わせて割る
- 「ゆっくり」「じっくり」「時間をかけて」は使わない。速度の話ではない
- 「相談アプリ」とは呼ばない。カウンセリングの前段階、とも言わない

## 読み上げ原稿

### ① フック

気持ちを相談したくなったとき、ChatGPTとは別の場所を作りました。

### ② 結論

Reflective AIです。答えを出さないAIを、実際に動くものとして作りました[泉川1]。

### ③ なぜ（山場）

ChatGPTでいいのでは、と思いますよね。役に立ちます。気持ちの相談を、解決すべき課題として受け取っている。間違えてはいません。

ただし、気持ちの相談では、何に対するもやもやかが、本人にもまだ決まっていないことが多い。そこに答えが出ると、その対象を、AIが先に決めてしまいます。

同じ文を、ChatGPTにも投げてみたんです。夫[泉川2]の言葉遣いが気になる。私にだけ命令口調になる。言い方を変えてほしい、と。共感のあと、すぐ、こう伝えてください、と台詞が出る。落ち着いたときに言う長い台詞。その場で返す短い台詞。境界の引き方。最後は、実際のフレーズを出してください、一緒に考えましょう、と、次の作業まで渡してきた。提案がどんどん来る。私は、考えが追い付きませんでした。速さの話ではありません。自分の工程が終わる前に、出口が来ていた、ということです。

Reflective AIでは、答えも台詞も出しません。聞こえた[泉川3]人を並べて、誰と話すかは、こちらが選ぶ。普段言えないことが言えて、抑圧されている自分や、こんなこと本当に言ったら、傷つけちゃうな、とも思いました。こう伝えてください、を先に渡していたら、その言葉は、私の口から出てこなかったと思います。

返す文を書くこと自体は、汎用AIにもできます。できないのは、返して止まる[泉川4]ことです。差[泉川5]は、能力ではありません。誰が、対象を決めるか、です。

### ④ どうやって（いちばん長く）

いまの画面では、誰と話すかは本人が選びます。最初からそうだったわけではありません。答えは出さない、と決めて、動くところまで作っていました。答えを出さなければ、対象は[泉川6]本人に残る。そう思っていました。

本人[泉川7]テストで、同じ、夫の言葉遣いの話を書いたんです。私は夫に話すつもりでした。なのに、当時のアプリは、話す相手として娘さん[泉川8]を出してきた。画面を見て、心の中では、はっきり思いました。違う、夫の話なのに、と。

答えを出さないAIを作っているつもりが、誰と話すかだけは、AIが決めていた。ChatGPTが対象を先に決めてしまう、と整理していた、[泉川9]まさにそのことを、自分の作ったものがやっていた。答えを出さない、と決めただけでは、足りなかった。対象を決める工程まで、本人[泉川10]に残す必要があった。

そこを直しました。聞こえた人[泉川11]を並べる。一人に絞らない。指名しない。誰と話すかは、本人が選ぶ。人が聞こえないときは、無理に相手役を出さない。今日はここまでにする、で閉じられるようにした。相手を選び直したときは、前の相手との話を持ち込まない。ステージを作り直す。

この半年[泉川12]でいちばん残っているのは、機能を足したことではありません。やらないと決めたことを、自分のアプリがやっていた、と気づいて、止めたことです。答えを出さない、は看板ではなく、画面の操作になるまで直した、ということです。

これが、この半年の作りです。判断[泉川13]しない。アドバイスしない。書いたことは保存されない。セッションが終われば、こちらにも残らない。しない、を貫いたのは、機能が足りないからではありません。その工程[泉川14]を、本人に残すためです。

### ⑤ いま

デモは公開していて、知人に使ってもらっているところです。書いた内容は保存されません。終了したら消えます。通知も、リマインドも、入れていません。

企業支援の現場で、経営者からこう聞きました。社内の人には伝えにくいこともあるだろう。会社の外から聞いてくれる人が必要だ、と。人の代わりを作ったのではありません。会社に届かない場所[泉川15][泉川16]です。保存しない、ほかの人に伝わらない、は、その場所の条件です。だから届け方は、個人が毎日払う形より、場を用意する企業や研修に届ける形を考えています。[泉川17]導入した事例、ではありません。十年見てきたことと、いまの作りから、そう置いています。[泉川18]

### ⑥ お願い[泉川19]

見ていただきたいのは、企画の正しさではありません。答えを出さないを、動くものとして、どこまで貫いて作ったか。誰と話すかまで、本人に残したか。それを、この半年の成果[泉川20]として提出します。

## 話すときのメモ

- ①のあと、ひと呼吸おく
- ③の「出口が来ていた」と「傷つけちゃうな」が山。ここだけ、間を取る
- ④は山を盛り直さない。事実を積む。「違う、夫の話なのに」のあと、一息
- ⑤の企業は一文の理由であって、導入事例ではない。検証した、とは言わない
- 「誰と話すかは、本人が選ぶ」で④を一度切ってから、「これが、この半年の作りです」へ
- スライドを後から足すときの枚数目安: 冒頭／同じ文の対比／娘さんが出てきた／社内には伝えにくい／見てほしいのは作り

## 長くなったときに削る順番

1. ③の「返す文を書くこと自体は、汎用AIにもできます。できないのは、返して止まることです。」
2. ④の「判断しない。アドバイスしない。書いたことは保存されない。」（「しない、を貫いた」の前まで）
3. ⑤の「知人に使ってもらっているところです」→「もう公開しています」
