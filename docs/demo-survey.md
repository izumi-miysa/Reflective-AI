# デモ感想フォーム（Googleフォーム用）

回答者に **Googleアカウントは不要** にできます（下記の設定を守ること）。

## フォーム作成手順

1. [Google フォーム](https://forms.google.com/) で新規作成  
2. タイトル例: `Reflective AI デモ感想（短いアンケート）`  
3. 説明例:  
   `体験後3分程度です。会話の中身は書かなくて大丈夫です。ログイン不要で回答できます。`  
4. 下の設問を追加  
5. **設定（歯車）→ 回答** で次を確認  
   - **メールアドレスを収集する** → オフ（収集しない）  
   - **回答を1回に制限する** → オフ  
   - （Workspaceの場合）**〇〇のユーザーに制限する** → オフ  
6. **ファイルアップロード設問は使わない**（ログインが必須になるため）  
7. 「送信」→ リンクをコピー  
8. `web/.env.local` と Vercel の環境変数に入れる  

```bash
NEXT_PUBLIC_SURVEY_URL=https://forms.gle/xxxxxxxx
```

シークレットウィンドウでリンクを開き、ログインなしで回答できるか必ず確認してください。

## 既存Googleフォームの直し方（2026-08-14 のアプリ変更に合わせる）

新規作成しなくてよい。いまのフォームを開いて、設問だけ直す。

1. **Q2** の文言を  
   「今、気になっていることを書いてみませんか」→「今、心にあることを書いてみませんか」に変更
2. **Q4** を差し替え  
   旧: 「相手役とお話された感じはいかがでしたか」  
   新: 「『ここで、相手を想定して話してみませんか』という出し方はいかがでしたか（相手が出なかった場合は、いちばん下）」

3. **Q5** を差し替え（旧Q5の「話を聞いてみませんか」のタイミングは、Q7の自由記述で拾う。現行コピーは「今のやり取りを少し離れて返してもらいませんか」）

   選択肢: 自然だった／ふつう／不自然だった／相手役と話さなかった  
   （旧Q4の内容を、ここに移す）
4. **Q6・Q7** はそのまま。Q7の説明文だけ、上記の自由記述に合わせて更新してよい
5. 直したら、シークレットウィンドウでリンクを開き、ログインなしで回答できるか確認する
