# デモ感想フォーム（Googleフォーム用）

回答者に **Googleアカウントは不要** にできます（下記の設定を守ること）。

## フォーム作成手順

1. [Google フォーム](https://forms.google.com/) で新規作成  
2. タイトル例: `Reflective AI デモ感想（短いアンケート）`  
3. 説明例:  
   `体験後3分程度です。会話の中身は書かなくて大丈夫です。ログイン不要で回答できます。`  
4. 下の設問を追加  
5. **設定（歯車）→ 回答** で次を確認  
   - **メールアドレスを収集する** → オフ（収集しない）  
   - **回答を1回に制限する** → オフ  
   - （Workspaceの場合）**〇〇のユーザーに制限する** → オフ  
6. **ファイルアップロード設問は使わない**（ログインが必須になるため）  
7. 「送信」→ リンクをコピー  
8. `web/.env.local` と Vercel の環境変数に入れる  

```bash
NEXT_PUBLIC_SURVEY_URL=https://forms.gle/xxxxxxxx
```

シークレットウィンドウでリンクを開き、ログインなしで回答できるか必ず確認してください。

## 設問案（そのままコピー可）

### Q1. 全体の印象（必須・ラジオ）
使ってみていかがでしたか

- とてもよかった
- よかった
- ふつう
- いまひとつだった
- よくなかった

### Q2. 入口（必須・ラジオ）
「今、心にあることを、少し書いてみませんか」という声掛けは入りやすかったですか

- 入りやすかった
- ふつう
- 入りにくかった

### Q3. 答えを出さないAI（必須・ラジオ）
Reflective AI が「答えや結論を出さない」感じは、伝わりましたか。

- よく伝わった
- ほぼ伝わった
- あまり伝わらなかった
- わからなかった

### Q4. 相手役とのやりとり（必須・ラジオ）
相手役とお話された感じはいかがでしたか

- 自然だった
- ふつう
- 不自然だった
- 相手役と話さなかった

### Q5. 話を聞く提案のタイミング（必須・ラジオ）
途中で「話を聞いてみませんか」と出ましたが、そのタイミングはいかがでしたか。

- ちょうどいい
- 早すぎた
- 遅すぎた
- わからなかった／覚えていない

### Q6. 終わり方（必須・ラジオ）
「今日はここまでにする」など、終わり方はわかりやすかったですか。

- わかりやすかった
- ふつう
- わかりにくかった

### Q7. 自由記述（任意・段落）
感想を自由にお書きください（会話の中身は書かなくて大丈夫です）
